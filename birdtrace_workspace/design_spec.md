# BirdTrace Explore — 设计说明

**版本：** 0.9 工作稿（服务 1.0 提案；编号与产品版本对齐，旧 v2.x 记录见 🔒 附录）
**日期：** 2026-07-07
**面向：** 朱雀会 / 中国观鸟记录中心（正式提案配套）+ 工程实现 / coder agent

> **文档约定：** 标 🔒 的章节是内部追踪内容，**制作对外交付版（1.0）时整节删除**。
> 其余章节按对外可读标准撰写：简单、直接，不重复论证。

## 基线（必读）

- **数据是很小的切片**：丽江/拉萨两城、2024–2025、集中在 5–6 月。12 个月维度的
  可视化（频率网格/多物种柱图/季节直方图）在 5–6 月外基本空——真实版如实显示稀疏，
  需要"数据全了什么样"时切示例数据版并整体标注（product spec §3 并用规则）。
- 地点选择器 = **两维（🏙️ 城市 + 🐦 鸟点）**，对外版城市锁定**丽江市 + 拉萨市**。「省/市/区县三级联动」的旧说法作废。
- 所有展示鸟点的地方用**规范化合并后的鸟点名**（`lib/spots.js`），不裸出 point_name；合并的点带「合并 N 处」chip。
- 构建分两版：对外版（`IS_PUBLIC`）隐藏工程细节文案；**所有新功能两版都要能跑**。
- 对外版「看什么」不带行程框架：城市 → 鸟点 → 该点全部记录名录。
- 基础 ≤640px 响应式已上线，新功能**不能破坏这个断点**；完整移动端 IA（§2）留后续。

## 现有设计语言（必须延续）

- 底色暖纸米色 `#fbf9f4`，不用纯白
- 1.5px 深棕描边 `#33312c`，几乎无阴影
- 金色 `#d9a92e` 只用于「系统的建议/答案」：★最优标签、速读结论、最佳窗口色带。不做装饰、不整行染色
- 弱化灰棕 `#b9b3a7` / `#cfc9bd`：低样本、次要信息
- 数字一律等宽字体；频率取整（83%，不写 83.3%）
- 地图：Leaflet + OSM，圆点大小=数量，颜色=分类
- 图表：CSS 柱图（现有 `.bars/.bcol`），不引入图表库（频率网格可例外）
- 信息气泡复用 `Info` 组件
- 空态写明原因（无记录 / 数据未导入 / 暂未覆盖），不写「加载失败」

## 一、桌面端

### 1.1 信息架构

顶部 3 个 Tab（对外版）：

- **看什么**（默认）：城市 → 鸟点 → 名录。目标鸟种是它的一个筛选视角。
- **何时去**：升级为多物种叠加柱图，原地升级不建新页。
- **探索**（新增，`?p=explore`）：落地页三张入口卡 → 分布图 / 地区探索 / 频率网格。

dev 版另有「去哪看」占位 tab，IS_PUBLIC 时过滤。

### 1.2 查询条

复用现有槽位样式（`.locslot`）。每页只显示用到的槽：

- 看什么：🏙️ 城市 + 🐦 鸟点（现有两维结构，不动）
- 何时去：省份 + 鸟种（+ 对比鸟种）
- 分布图：鸟种搜索
- 地区探索：🏙️ 城市（丽江市 / 拉萨市；dev 版可全量）
- 频率网格：省份（云南 / 西藏）

### 1.3 看什么（polish + 目标鸟种）

真实数据。基线 = public demo 轮的两维选择器 + 规范化鸟点，不动结构。

```
查询条：[城市 ▾] [鸟点 ▾]（下方 chip：鸟种数 · 清单数 · 合并 N 处）
速读结论：共 N 种 · 最常见「XX」YY%
数据行：基于 N 份报告 [?] · 数据来源：中国观鸟记录中心 · 2024–2025
[ 全部鸟种 | 目标鸟种 ]                    [★ 我的鸟种(N)]
名录列表（SpeciesChecklist，现有）
```

**目标鸟种视角（新）：**

- 两个并排切换按钮，默认「全部鸟种」，激活态用墨色处理（不用金）
- 切到「目标鸟种」：只显示 useMarks 里未标「已见」的鸟种，频率排序不变
- 标「已见」→ 该行实时从列表消失
- useMarks 为空：列表同全部视角，顶部加一条暖黄细边框提示「标记已见鸟种后，此处将只显示未见鸟种」

**Polish 点（仅限这些）：** thin 数据措辞、空态文案（无记录 vs 未导入）、报告弹窗「明细待抓」标注（对外版按 IS_PUBLIC 隐藏工程注释）、导出鸟单文件头（地区+时段+来源）、鸟点别名表人工过一遍丽江/拉萨下拉。

**新建组件：** 视角切换按钮组、空标记引导提示条。其余全部复用。

### 1.4 何时去（多物种柱图）

真实数据，原地升级。

```
查询条：[省份 ▾] [🐦 鸟种] [+ 添加对比鸟种]
标签：[黑颈鹤 ×] [灰鹤 ×]（最多 4 种）
结论：最佳窗口 N–M 月 · 峰值 XX%（多物种：窗口交集 N–M 月 / 无共同窗口）
图表：多物种叠加柱图 + 交集色带
图例：■ 黑颈鹤（金） ■ 灰鹤（深棕） …
数据行：云南 · N 份报告 [?] · 数据来源：中国观鸟记录中心
```

规则：

- 颜色：第 1 种金，第 2–4 种深棕 / 橄榄棕 / 蓝灰（暖调，不用红绿蓝）
- 交集 = 各鸟种频率均达阈值的月份（阈值工程自定），半透明色带高亮（复用 `.window`）；无交集显示「所选鸟种无共同最佳时间窗口」，不画色带
- 某鸟种无数据：柱不画，图例旁灰字「暂无数据」
- 超 4 种：按钮置灰 + 提示「最多同时对比 4 个鸟种」
- 删除标签 ×：图表实时更新

**新建组件：** 鸟种标签组、添加对比搜索框（复用 datalist）、交集逻辑（扩展 bestWindow）、图例。

### 1.5 探索落地页

新 Tab，纯导航。三张等宽入口卡（暖纸 + 细边框）：

| 卡 | 一句话 | 备注 |
|---|---|---|
| 鸟种分布图 | 选一种鸟，看它在哪里 | 卡上带「示例数据」badge |
| 地区探索 | 选一个地区，全面了解观鸟资源 | |
| 频率网格 | 看全年鸟种频率分布规律 | |

点卡进子页，子页状态走 `&sub=distribution|region|grid` URL 参数（演示要能直链到具体子页，参数族见 §3.4）。

**新建组件：** 落地页容器、ExploreCard、「示例数据」badge（全局复用）。

### 1.6 分布图（filler 示例数据）

```
← 返回探索
鸟种分布图 [示例数据]        ← badge 始终可见
查询条：[🐦 鸟种搜索]
Leaflet 地图：圆点大小=记录数，颜色=主要季节
图例：● 春(草绿) ● 夏(砖红) ● 秋(橙棕) ● 冬(蓝灰)，均低饱和
底部：本图使用示例数据，坐标与数量均为示意值
```

规则：

- 标题旁 badge + 底部说明，两处都要；**不出现**「数据来源：中国观鸟记录中心」
- 预置 3–5 个鸟种的 filler 数据；鸟名地名真实，数字坐标为示意值
- 圆点弹窗：地点名 + 「记录数（示意）」+ 主要季节 + 季节分布小条
- 搜不到：「未找到该鸟种数据」
- badge 显隐由 provider `isDemo` 驱动

**新建组件：** DistributionMap 圆点层、圆点弹窗、季节图例、底部说明条。

### 1.7 地区探索页（真实数据）

覆盖云南 + 西藏。地点槽 = 城市选择（对外版丽江/拉萨），**不是三级联动**。

页面五个区域（顺序可调，概览数字 + 数据来源必须第一屏可见）：

1. **概览数字**：鸟种总数 / 报告总数 / 年份范围（OverviewStats，新建）
2. **热点地图**：复用 RegionMap；热点名用规范化名；交互与鸟点叶子页一致（选中后压缩为 160px 缩略图 + 高亮环）；点圆点 → 热点名 + 报告数 → 「进入该点名录」下钻到 SpeciesChecklist
3. **鸟种列表**：前 20–50 种，中文名 + 频率% + 最佳月份（RegionSpeciesList，新建，轻量无勾选）
4. **季节直方图**：12 月报告量，延续现有柱图风格（SeasonHistogram，新建）
5. **近期记录流**：见 1.8

标题下第一屏：「数据来源：中国观鸟记录中心 · 覆盖：云南、西藏 · 2024–2025」。

超出覆盖：只显示「当前暂未覆盖该地区，数据覆盖范围：云南、西藏」，其余区域全部隐藏。

### 1.8 近期记录流（地区探索页内嵌区块）

```
近期记录
数据来源：中国观鸟记录中心 · 最新记录：YYYY-MM-DD
YYYY-MM-DD  纳帕海        23种  [展开 ▾]
YYYY-MM-DD  碧塔海        [明细待抓]
…（最近 20–50 条，倒序）
```

- 地点名走规范化层
- 有明细：内联展开鸟种列表（不弹窗）；「明细待抓」灰斜体，不可展开
- 无数据：区块保留，显示「暂无近期记录」，不影响其他区域

**新建组件：** RecentRecords 容器、RecordRow（含展开）。

### 1.9 频率网格（真实数据，省级）

```
← 返回探索
频率网格
数据来源：中国观鸟记录中心 · 覆盖：云南、西藏 · 2024–2025
查询条：[省份 ▾]  排序：[最高频率月 ▾ | 科属]
网格：行=鸟种，列=1–12 月，格深浅=频率
图例：░ 无记录  ▒ 低频  █ 中频  ██ 高频 · 斜纹 = N<15 仅供参考
分母行：网格底部一行等宽数字 = 各月完整报告数
```

格子规则：

- 颜色从浅米渐变到深金棕（金色系，不用红绿热力图）
- N=0：空白/极浅灰，明显区别于有数据格
- N<15：叠斜纹（复用 `.thin` 约定）
- 点击/悬停：格子描边高亮 + tooltip「物种 · 月份 · 频率 X% · 样本 N 份」
- 排序默认按最高频率月，可切科属（科属数据 = `taxa` 表现成的 `family_name`/`order_name`）
- 覆盖外省份：「当前暂未覆盖该省份」，不画空网格

工程备注：行多（>100）时可用 `<table>` + sticky 表头或虚拟滚动，视觉要求不变。

**新建组件：** FrequencyGrid（本轮最重要）、格子 tooltip、颜色图例、排序切换、分母行。

## 二、移动端 H5（留后续，不在本轮）

本轮只要求：**新功能不破坏现有 ≤640px 断点**。以下完整移动端 IA 留档，后续排期用。

🔒 注（内部，交付版删除）：1.0 提案的集成形态之一是官方独立小程序（product spec
§1 🔒 合作提案方向）。若定为小程序，本章 §2.3 的"同一 React 代码库 + H5"技术方向
需重估（小程序原生 vs WebView 内嵌 H5）；信息架构（§2.1 取舍、§2.2 底部三 tab）
不受影响，可直接沿用。

### 2.1 取舍

保留：看什么（核心）、目标鸟种切换、地区探索简化版（去地图，概览数字 + 热点文字排行）、近期记录流、「明细待抓」标注。

砍掉：频率网格（大表格小屏不可读）、多物种柱图（规划型重交互，非现场快查）、分布图（filler 无实用价值）、探索落地页（没剩几个入口，并进底部导航）。

### 2.2 结构

底部 3 Tab：**看什么 / 地区探索 / 我的**。

- **看什么**：全下拉选条件（城市→鸟点→月份）→ 大按钮「查看鸟种名录」→ 名录页（频率条 + 中文名 + % + 标记按钮，顶部固定面包屑和数据来源行，全部/目标切换固定在列表顶）
- **地区探索**：选城市 → 内部小 tab「概览 / 热点 / 近期记录」；热点为文字排行列表，点名字进名录
- **我的**：useMarks 已见清单，每行可取消；空态引导「在看什么页点标记按钮记录已见」；底部导入入口

### 2.3 移动端规范

- 同一 React 代码库，App 入口按 viewport 分发到独立 MobilePage 组件；共享数据层和 useMarks，不共享布局
- 同一套 CSS 变量；正文 ≥16px；触控区 ≥44px；原生 `<select>`（微信兼容最好）；无 hover 态
- 数据来源收成一行「数据：中国观鸟记录中心」，固定标题下不随滚动消失
- 移动端无「示例数据」场景（分布图已砍）

## 三、横切规范

### 3.1 数据诚实标注（spec §5 硬约束）

| 功能 | 标注 | 位置 |
|---|---|---|
| 看什么 / 目标鸟种 | 来源 + 年份 | 数据行，第一屏 |
| 分布图（filler） | 「示例数据」badge + 底部说明 | 标题旁，始终可见 |
| 地区探索 / 频率网格 | 来源 + 覆盖：云南、西藏 + 年份 | 标题下，第一屏 |
| 何时去 | 来源 | 底部数据行，第一屏 |
| 近期记录流 | 来源 + 时间范围 | 区块头部 |

badge 规范：金色细边框小标签，暖纸底，小号字，粘性定位不随滚动消失。显隐只由 provider `isDemo` 驱动——isDemo=false 时自动消失，不改前端代码。

真实数据功能**绝不出现**「示例数据」字样；filler 功能**绝不出现**「数据来源：中国观鸟记录中心」。

### 3.2 空态 / 异常

- 写明具体原因：无记录 / 数据未导入 / 暂未覆盖该地区
- 不崩溃、不空白页；只有受影响区块显示空态，其余正常
- 地图加载失败：文字占位，页面其余正常

### 3.3 视觉建议（最终由人定）

- 金色是唯一主色；多物种第 2–4 色从调色板衍生（深棕/橄榄棕/蓝灰）
- 频率网格浅米→深金棕，不用红绿热力图；季节四色低饱和
- 页面节奏：查询条 → 速读结论 → 主内容 → 数据说明；区块间细线分隔，不用色块
- 加载中用文字「加载中…」，无 spinner；hover 用描边加深/底色微调；标记反馈即时、动画克制

### 3.4 URL 深链方向

eBird 全站遵循「视图=稳定路径、过滤=query string、处处可分享」（研究 §11）。BirdTrace
现在只有 `?p=`，本轮起按下面方向演进（本轮只做前两条，其余留架构余地）：

- 本轮：探索子页用 `&sub=distribution|region|grid`；演示者能把具体子页存书签/直链。
- 本轮：「看什么」把当前城市/鸟点写进 `&r=`（城市 id 或 point_id），刷新/分享不丢状态。
- 后续：月份 `&m=`、鸟种 `&spp=`、个人视角 `&personal=`，对齐 eBird barchart 参数族。

## 五、招牌种 badge（加分项，可选）

某鸟点相对全省基线最有代表性的种（eBird Iconic Birds 简化版）。回答「这个点值不值得
专程」——纯频率榜答不了。

- 算法：`点频率 ÷ 全省频率`。点频率来自 points/*.json；省频率由 province bundle
  的月度计数 ÷ total_reports 求全年比。倍数 > 3 且点样本 N ≥ 5 才显示。
- 呈现：鸟点叶子页名录里，命中的种在频率旁加金色小 badge「全省 N 倍」（金 = 系统
  的建议，符合用色规则）+ ⓘ 口径说明。每点最多 3 种。
- 全部客户端计算，两个既有 fetch，不动导出管线。做不完不阻塞演示。
